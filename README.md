# CalTalk

카카오톡 채널을 통해 일정을 조회하고 관리하는 대화형 일정 관리 서비스입니다.

## 현재 단계

- Stage 5: 카카오톡 채널 챗봇 PoC 조건부 종료
- Stage 6: 정식 개발 환경 및 저장소 구성

## 디렉터리

- `backend/`: 정식 백엔드 애플리케이션
- `frontend/`: 웹 프론트엔드 애플리케이션
- `docs/`: 정식 개발 기준 문서
- `infra/`: 배포 및 인프라 구성

## 개발 원칙

- PoC의 `server.js`는 검증 참고 구현으로만 사용합니다.
- PoC 코드를 정식 서비스 코드로 직접 복사하지 않습니다.
- 검증된 계약과 테스트 결과를 정식 백엔드에 다시 구현합니다.
- 비밀값과 로컬 환경설정 파일은 Git에 커밋하지 않습니다.
