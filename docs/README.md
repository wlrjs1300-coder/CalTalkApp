# CalTalk 문서 관리

이 폴더에는 정식 개발에 직접 사용하는 승인 문서만 둡니다.

## 원본 문서 위치

기존 기획서와 PoC 문서는 다음 외부 폴더에 보존합니다.

`C:\Users\User\Desktop\caltalk`

## 이관 원칙

1. 원본 파일은 이동하거나 삭제하지 않습니다.
2. 정식 개발 기준으로 확정된 문서만 이 폴더에 복사합니다.
3. 초안, 중간본, 중복본은 정식 저장소에 포함하지 않습니다.
4. 민감정보와 임시 터널 주소가 없는지 확인한 뒤 추적합니다.
5. 문서 복사는 별도 작업에서 수행합니다.
