## 문서 우선순위

문서 내용이 충돌할 경우 다음 순서로 판단합니다.

1. 기술 설계서
2. 화면·기능 명세서
3. MVP 서비스 기획서
4. PoC 계획서의 검증 결과와 제한 사항

카카오 플랫폼에서 실제 측정된 제약과 보안 결과는 PoC 계획서의 최신 검증 결과를 우선합니다.

## 관리 원칙

1. 원본 문서는 외부 보관 폴더에 유지하고 삭제하지 않습니다.
2. 이 저장소에는 정식 개발 기준으로 승인된 문서만 포함합니다.
3. 초안, 백업본, 검수 중간본과 작업 프롬프트는 포함하지 않습니다.
4. 문서 변경은 별도 브랜치와 커밋으로 추적합니다.
5. 실제 사용자 식별값, 토큰, 헤더값, 연결 코드와 임시 터널 주소를 기록하지 않습니다.
6. PoC의 `server.js`는 참고 구현이며 정식 서비스 코드로 직접 승격하지 않습니다.
